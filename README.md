# Indomitus Tech Tree

## Русский

Интерактивное древо исследований для мода **Indomitus** к игре **Call to Arms — Gates of Hell: Ostfront**. Проект помогает просматривать исследования, их стоимость и необходимые предыдущие исследования.

В подробностях исследования доступны состав, вооружение и интерактивный просмотр извлечённых 3D-моделей юнитов. Модели загружаются по запросу и после первого просмотра доступны в автономном PWA-кэше. Геометрия показана в статической позе; материалы упрощены, если исходные текстуры находятся только в базовой игре.

Мод в Steam Workshop: [Indomitus](https://steamcommunity.com/sharedfiles/filedetails/?id=3494196322)

## English

An interactive technology tree for the **Indomitus** mod for **Call to Arms — Gates of Hell: Ostfront**. This project helps users browse technologies, their costs, and prerequisite research.

Research details include composition, armament, and an interactive viewer for extracted unit models. Models load on demand and remain available in the offline PWA cache after their first view. Geometry is shown in a static pose; materials are simplified where the original textures exist only in the base game.

Mod on Steam Workshop: [Indomitus](https://steamcommunity.com/sharedfiles/filedetails/?id=3494196322)
