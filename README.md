# Indomitus Tech Tree

## Русский

Интерактивное древо исследований для мода **Indomitus** к игре **Call to Arms — Gates of Hell: Ostfront**. Проект помогает просматривать исследования, их стоимость и необходимые предыдущие исследования.

Мод в Steam Workshop: [Indomitus](https://steamcommunity.com/sharedfiles/filedetails/?id=3494196322)

## English

An interactive technology tree for the **Indomitus** mod for **Call to Arms — Gates of Hell: Ostfront**. This project helps users browse technologies, their costs, and prerequisite research.
